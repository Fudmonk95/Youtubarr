# Youtubarr v1.0.0

Brand-new v1 architecture:

- rebuilt Arr-style YouTube-red UI;
- first-run administrator and Arr connection wizard;
- Series/Sonarr and Music/Lidarr enabled by default;
- optional Movies/Radarr module controls whether the Movies menu exists;
- one Compose service / one Youtubarr container;
- FUSE daemon runs inside that same container;
- automatic root discovery and local mapping generation;
- virtual symlink library for TV, music and optional movies;
- direct progressive MP4, split video/audio remux and M4A virtual playback;
- playlist-to-season and playlist-to-album ordered mapping;
- Portainer and Proxmox-LXC deployment documentation;
- host mount preparation made persistent with systemd;
- explicit DUMB/Zurg coexistence rules.
